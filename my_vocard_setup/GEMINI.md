# Project Guidelines & Agent Instructions

## Superpowers Protocol
- **Always use Superpowers**: The agent must strictly follow the Superpowers workflow (`using-superpowers`) for all tasks.
- **Brainstorming First**: For any new features, planning, component additions, or structural changes, always invoke `brainstorming` before writing code or making plans.
- **Systematic Debugging**: For any bug fixes, error tracebacks, or failing tests, always invoke `systematic-debugging` before attempting fixes.
- **Skill Checks**: Always check for and invoke relevant skills before taking action or answering complex technical requests.
